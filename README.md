# MusicDream

Prototype landing page for MusicDream: animated, beat-synced music videos for independent artists, plus sponsorship placements for instrument and accessory brands.

This is a direction prototype, not a live offer. The contact form does not send anything.

- `index.html` – the whole page (no build step)
- `assets/` – frames and a short hero loop from our own videos *Nostalgic Night* and *We Gave Our Shadows to the Sun*

Live preview via GitHub Pages: https://kami2025.github.io/musicdream/
